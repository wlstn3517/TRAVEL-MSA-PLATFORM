===============================================================================
Travel MSA Platform

Spring Cloud 기반 MSA 아키텍처로 구현한 여행지 정보 플랫폼입니다.

사용자는 여행지 정보를 검색하고 조회할 수 있으며 로그인 및 마이페이지 기능을 사용할 수 있습니다.
관리자는 관리자 페이지를 통해 사용자 관리, 쿠폰 정책 관리, 배치 로그 조회 등의 기능을 수행할 수 있습니다.
